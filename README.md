# Ashu Catering Service — Homepage

A responsive, editorial-style homepage for Ashu Catering Service, inspired by the existing catering site and reference screenshots.

## Preview

Once GitHub Pages is enabled, the homepage can be published from the `main` branch and repository root.

## Run locally

No build tools are required.

1. Download or clone the repository.
2. Open `index.html` in a browser.

## Files

- `index.html` — homepage hero slideshow and welcome section
- `about.html` — separate About Us page
- `services.html` — catering services page
- `menus.html` — menu categories and quotation enquiry
- `gallery.html` — food and event gallery
- `contact.html` — contact details and WhatsApp enquiry
- `styles.css` — responsive styling, typography and layouts
- `script.js` — mobile navigation, active navigation state and current footer year

## Included in this first homepage

- Full-height food photography hero and enquiry call-to-action
- About/story section
- Catering service highlights
- Brand quote section
- Image gallery
- WhatsApp enquiry link
- Responsive mobile navigation and reduced-motion support

## Before publishing

- Review the WhatsApp contact number in `index.html`.
- Replace stock photography with Ashu Catering Service's own food and event photos when ready.
- Confirm the final copy and any claims about years of experience before publishing.
- Enable **Settings → Pages** and deploy from the `main` branch, root folder, if you want a GitHub Pages preview.
